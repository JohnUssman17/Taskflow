
# Task.Flow ✅ - Task Management App

Live Demo 👉 **https://taskflow--johnussman.replit.app**

A simple and powerful Task Management application built with Java Spring Boot and Docker.

---

### 🚀 Features
- Create new tasks
- Mark tasks as complete / incomplete
- Delete tasks
- Clean and responsive UI
- Persistent storage

### 🛠️ Tech Stack
- **Backend:** Java 17, Spring Boot
- **Frontend:** Thymeleaf / HTML / CSS
- **Database:** H2 / MySQL
- **DevOps:** Docker, Maven
- **Deployment:** Replit

### 🔗 Links
- **Live App:** https://taskflow--johnussman.replit.app
- **GitHub:** https://github.com/JohnUssman17/Taskflow

### 📦 How to Run Locally
```bash
# Clone the repo
git clone https://github.com/JohnUssman17/Taskflow.git

# Go to project folder
cd Taskflow

# Run with Docker
docker-compose up --build

# Or run with Maven
./mvnw spring-boot:run

App will run at http://localhost:8080
